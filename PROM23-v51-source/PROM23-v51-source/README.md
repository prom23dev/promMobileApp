## Запуск на этом Mac

```sh
cd /Users/prom23/Projects/prom23-mobile/mobile
sh scripts/local-npm.sh run export:web
cd ..
/Users/prom23/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node preview/index.mjs
```

В текущем окружении основной Node устарел для SDK 57. Скрипт использует уже имеющийся bundled Node 24.19, не меняя глобальные настройки. На другой машине: Node 22.13+ (рекомендуется 24 LTS), `npm ci`, `npm run web` или `npm start` для устройства. Для native development build нужны полный Xcode 26.4+ либо Android SDK и соответствующее окружение. Минимальные ОС SDK 57: iOS 16.4+ и Android 7+; поддержку более старых iPhone нужно согласовать отдельно.

```sh
sh scripts/local-npm.sh test
sh scripts/local-npm.sh run typecheck
sh scripts/local-npm.sh run export
```

Web-превью предназначено для проверки интерфейса. Оно не заменяет тесты подписанных нативных сборок. `eas.json` содержит только internal preview, пакет `ru.prom23.preview` временный; принадлежность/доступность release namespace и аккаунты издателя ещё не подтверждены. `npm run check:release` намеренно завершается ошибкой, перечисляя незакрытые условия выпуска. Этот диагностический скрипт сам по себе не блокирует ручную загрузку файла в магазин.

## Что нужно для продолжения интеграции

1. Тестовый сайт уже известен: https://prom.myfast.space/. Для проверки закрытых сценариев нужны тестовые аккаунты физлица/ИП/юрлица и подтверждённые полномочия организации.
2. Возможность доработки серверной части, доступ разработчика к тестовому Bitrix и обезличенной базе/медиа. В переданном архиве нет ядра Bitrix, БД и `upload`.
3. Издатель, название/география приложения, аккаунты Apple Developer и Google Play Console, интеграции банка/СБП/ККТ/ОФД, доставки, 1С и ЭДО, правила B2B полномочий.

До подключения необходимо исправить присоединение к существующей организации по ИНН/КПП, работу с карточными реквизитами, доступ к PDF, обработку удаления аккаунта и отзыва сессий. Подробности и границы статического вывода — в аудите.

Полное соответствие законодательству и магазинам не установлено: нет фактической схемы обработки данных, реквизитов и договоров, проверки всех актуальных редакций и релизных сборок. Скорость уровня ВсеИнструменты/WB/Ozon/Яндекс Маркета является ориентиром; сравнительных замеров на устройствах нет. Доступность HTTP и тесты стенда не заменяют замеры нативных приложений. Для native build нужно задать EXPO_PUBLIC_LOCAL_API_URL на доступный устройству HTTPS API; текущий HTTP-стенд по IP предназначен только для проверки тестовых операций в браузере.
