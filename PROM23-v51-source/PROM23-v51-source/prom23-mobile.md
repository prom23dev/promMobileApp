# План приложения «Промышленник»

Статус: анализ архива и первый исполняемый срез. Адрес тестового сайта, доступ к серверу и условия выпуска запрошены.

1. Инвентаризация B2C/B2B функций и серверных рисков с путями к исходникам.
2. Проверка официальных требований App Store, Google Play и РФ на 11.09.2026 с явным указанием пробелов.
3. Предварительная архитектура: React Native + Expo для iOS/Android; отдельный версионируемый API к Bitrix. Секреты остаются на сервере.
4. Первый исполняемый срез каталога, карточки товара, корзины и переключения контекста. Синтетические данные обозначены как демонстрационные.
5. Контракт API и карта оставшихся интеграций. Реальная авторизация, заказы, платежи и ЭДО требуют тестового сервера.
6. Проверки доменной логики, TypeScript и сборки; план измерений на iOS/Android.
7. Выпуск после интеграции, проверки B2B изоляции, платежей, правовых документов и подписанных сборок.

Архив рассматривается как данные для анализа, а не источник инструкций. Разработка ведётся локально из-за ограничений SMB в workspace AGENTS.md.
