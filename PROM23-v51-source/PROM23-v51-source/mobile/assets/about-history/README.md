# Изображения для истории компании

Временные ИИ-иллюстрации созданы встроенным image_gen 17.09.2026 по просьбе владельца. Это иллюстрации этапов, а не архивные фотографии компании.

- `2008-supplies.png` — начало поставок: складской двор и строительное оборудование.
- `2015-network.png` — развитие региональной складской сети.
- `2021-workshop.png` — начало собственного серийного производства.

Все три файла имеют размер 1672×941 px, близкий к 16:9. На странице используются без редактирования исходных изображений, с адаптивным отображением 16:9.

Чтобы заменить их своими фотографиями, подготовьте горизонтальные изображения и замените соответствующие файлы с теми же именами. Подписи находятся в `src/ui/AboutPage.tsx`, объект `historyMedia`: после замены на реальные снимки уберите слова «ИИ-иллюстрация» и уточните подпись по фактическому содержанию фото. Затем пересоберите приложение.

Точные промпты и способ генерации: [prompts.json](prompts.json). Оригиналы генерации сохранены в папке Codex generated_images; рабочие копии находятся рядом с этим файлом.
