# Происхождение локального каталога

Снимок публичного тестового сайта владельца: [prom.myfast.space](https://prom.myfast.space/). Импорт выполнен 11 сентября 2026 года, 06:12:03–06:12:34 UTC (09:12:03–09:12:34 по Москве). Разрешение на использование собственного сайта и локальное развёртывание дано пользователем в задаче.

В `catalog.json` сохранены 25 реальных каталожных позиций из 8 категорий: вышки-туры — 3, лестницы — 3, леса и комплектующие — 4, инструменты/станки — 4, вибротехника — 3, бетонные работы — 3, опалубка — 2, сетка/тенты/плёнка — 3. Это ограниченная выборка для разработки интерфейса, а не весь ассортимент и не восстановленная база Битрикс.

## Что взято с сайта

- Название, код/артикул, текущая отображаемая цена из основной карточки, характеристики и дословная подпись наличия.
- Фотография каталожной карточки скопирована без генерации, ретуши, обрезки и перекодирования. Изображения находятся в `mobile/assets/catalog/`; статические импорты — в `mobile/src/catalog-assets.ts`, экспорт `catalogAssets`.
- `sourceUrl` и `imageSourceUrl` содержат публичные адреса исходной карточки и фотографии. `importedAt` — время извлечения позиции в снимок. `priceSource` всегда `staging-snapshot`.
- `catalog-evidence.json` содержит исходный текст цены, SHA-256 страницы на момент чтения, SHA-256 и размер каждого изображения. Всего 3 967 129 байт изображений. Некоторые ссылки сайта оканчиваются на `.jpg`, но возвращают PNG; расширение локального файла определено по содержимому.

Цены преобразованы из рублей в целое число копеек. Не переносились перечёркнутые цены, процент скидки, рейтинги, отзывы, сроки доставки и платёжные реквизиты. Товары без числовой цены не включены. Цены и подписи наличия действуют только как содержимое снимка тестового сайта; они не являются обещанием актуальной цены, поставки или наличия на складе.

## Что является параметром локального стенда

`stock = 20`, `stockSource = local-test-limit` — одинаковый **тестовый лимит количества** для проверки локальной корзины. Это не остаток на складе. Не показывайте его покупателю как реальные «20 шт. в наличии». На публичных страницах отображаются только «В наличии мало»/«В наличии много», без точного остатка; они сохранены отдельно в `availabilityText`.

`unit = ед.`, `unitSource = local-catalog-position` означает одну выбранную каталожную позицию для локальной корзины. Единица продажи/кратность упаковки в подключённой товароучётной системе не подтверждена. Позиция может представлять комплект или упаковку; её название и характеристики сохранены дословно. Реальный checkout должен получить единицу продажи, кратность и остаток от сервера.

Категории укрупнены для локальной навигации. `kind` — техническая категория отображения: `tower`, `ladder`, `scaffold`, `tool`, `equipment`, `mixer`; это не дополнительная характеристика производителя. `id = prom-<публичный ID товара>` сохраняет связь с публичным идентификатором исходной карточки.

## Ограничения исходных данных

В некоторых карточках источник повторяет «Вес, кг» с разными значениями: например у ВСПТ 0,7×1,6, 2,8 м указаны 63.6 и 64. Разные пары «название/значение» сохранены, полные одинаковые повторы удалены. Не следует выбирать спорное значение для расчёта доставки без подтверждения. В интерфейсе ключ строки характеристик должен включать индекс или значение, а не только название.

Для prom-372 (плёнка 2×25 м) исходная главная фотография содержала противоречащие названию надписи 2×10 м и 20 м². Вместо неё выбрана фотография 06 из галереи той же карточки без противоречащих размеров. Это выбор готового кадра сайта, не изменение изображения.

Картинки ряда товаров уже содержат текст/инфографику от исходного сайта. Эти надписи не добавлены приложением. Для более единообразной сетки карточек в последующей итерации можно выбрать альтернативный кадр из галереи, сохраняя связь с правильным SKU.

В исходниках сайта изучены шаблон каталога и `site-source/local/templates/main/components/bitrix/catalog.element/vyshki/template.php`: подписи «много/мало» формируются сравнением количества с 20, поэтому точное количество по подписи восстановить нельзя. PHP не исполнялся.

## Способ получения и проверка

Выполнены только публичные HTTP GET к главной странице, `/catalog/`, первым страницам четырёх категорий, 25 карточкам и 28 изображениям (25 включены, ещё 3 прочитаны для проверки/выбора кадра плёнки). Одновременно работало не более двух запросов, без перебора идентификаторов, авторизации, API изменения состояния, отправки форм и взаимодействия с корзиной сайта. Полученные cookie не сохранялись и не отправлялись. В распространяемых файлах нет исходного HTML, скриптов сайта, cookie, авторизационных данных или персональных данных.

Проверены: 25 уникальных ID, 25 существующих локальных изображений с корректной сигнатурой JPEG/PNG, положительные целочисленные цены в копейках, наличие SKU и характеристик, правильный домен исходных ссылок, статическая карта всех 25 require. Визуально просмотрены все 25 выбранных изображений. Продуктовые данные не являются подтверждением соответствия товара или приложения требованиям законодательства/магазинов приложений.
