## Оставшаяся проблема зависимостей

`npm audit` после замены `uuid` для `xcode` показывает **3 записи moderate** в одной цепочке `decode-uri-component → query-string → expo-router`: [GHSA-vcc3-ghjq-m6fr](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr), отказ в обслуживании на некорректном percent-encoded вводе. Подробности — `npm-audit.json`. Это незакрытый пункт до выпуска. Автоматически предложенное понижение Expo Router/Expo до несовместимых старых версий не применялось. Нужны исправленный совместимый релиз либо проверенный воспроизводимый патч с тестами ссылок и маршрутизации.

`uuid` закреплён для `xcode` на 11.1.1 вместо уязвимого старого выпуска; после этого генерация Xcode-проекта проходит. [Соответствующее предупреждение](https://github.com/advisories/GHSA-w5hq-g745-h8pq). Такая замена не доказывает безопасность всех зависимостей, а только закрывает известную цепочку этого предупреждения.

## Не выполнено

Полный Xcode/iOS Simulator и Android SDK на машине отсутствуют. Не созданы подписанные IPA/AAB, не выполнены тесты на iPhone/Android, VoiceOver/TalkBack, 16 KB, IPv6/NAT64 и медленной сети. Нет аккаунтов издателя, тестовой БД/ядра сайта, серверной авторизации, платежей/ККТ, документов/ЭДО, возвратов и удаления аккаунта. App Privacy/Data safety, правовые документы, инфраструктура обработки данных и полнота законодательства на контрольную дату не подтверждены.

## Повтор проверки

Из каталога `mobile`: `sh scripts/local-npm.sh test`, `sh scripts/local-npm.sh run typecheck`, `sh scripts/local-npm.sh run export`. Для браузерных сценариев запустить `node scripts/preview-server.cjs`, затем `node scripts/browser-smoke.cjs`. На другой машине нужен пакет `playwright` и `CHROME_PATH` к отдельному Chrome; скрипт не читает личный профиль браузера. Нативные проекты воспроизводятся через `npx expo prebuild --no-install`; они не включены в архив управляемых исходников.
