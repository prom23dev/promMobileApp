# Мобильный дизайн, итерация 2

Цель: профессиональная покупка строительного оборудования с телефона. Ориентиры — нативные приложения Ozon, Wildberries, Яндекс Маркет, ВсеИнструменты.ру; доступные источники и границы наблюдений зафиксированы в `08-native-app-benchmark.md`.

## Решение

Главный экран начинается с региона/контекста покупателя и большого поиска. Небольшие подборки ведут в реальные категории. Основное пространство занимают фотографии и товары. Каталог имеет отдельную структуру категорий и рабочие фильтры, а не повторяет главную. На карточке — крупное фото, цена, единица, характеристики и закреплённое действие. В корзине — состав, получатель покупки, итог и переход к оформлению. B2B остаётся доступен через контекст покупателя и кабинет, без большого переключателя на каждом экране каталога.

Цвета: `#FFFFFF` (поверхности), `#F5F6F8` (фон), `#202338` (основной текст), `#3D4471` (бренд), `#D93916` (действия с белым текстом), `#FF4016` (исходный акцент бренда). Вторичные цвета — производные этих токенов; зелёный применяется только к состояниям, подтверждённым данными. Из каталога нельзя выводить выдуманные рейтинги, скидки и сроки доставки.

Типографика: системные SF/Roboto. Заголовки 24/28 с плотным полужирным начертанием, основной текст 14–16/20–23; цена 22–26, служебный текст 11–12. Контроль сенсорных зон от 44. У кнопок, полей, фильтров и вкладок есть доступные названия; системный размер текста сохраняется.

Характерная деталь: реальные фотографии профессионального оборудования и сценарные подборки «На высоте», «Бетонные работы», «Для ремонта». Это навигация по существующим разделам, без придуманной рекламной акции.

```
регион ⌄                        Для себя ⌄
[ Поиск по товарам и артикулам              ]
[ фото + подборка ][ фото + подборка        ]
категории →
Товары из каталога            фильтры/сорт.
[ большое фото ][ большое фото ]
[ цена / ед.   ][ цена / ед.    ]
[ название     ][ название      ]
[ + в корзину  ][ + в корзину   ]
Главная · Каталог · Избранное · Корзина · Кабинет
```

Небольшая метка локального режима раскрывает подробности по нажатию. В checkout слова «тестовый заказ» остаются прямо на кнопке и в подтверждении. Приложение показывает фактическое сохранение в локальную базу, не выдавая его за заказ на действующем сайте. Настоящие оплаты, чеки, ЭДО и полномочия организаций не симулируются как выполненные.

Уточнение владельца 11.09.2026: функциональный состав определяется исключительно её сайтом. ВсеИнструменты.ру — основной визуальный/UX-ориентир, остальные магазины — дополнительные; их функции не являются требованиями. Для каждого экрана проверяется соответствие `docs/02-feature-parity.md` и исходникам сайта. Тестовые заглушки интеграций не заменяют оригинальный процесс и не считаются реализацией всего функционала.
