## Подтверждённые контракты и расхождения

- Auth: source REST methods `user.registration.email/phone`, `user.authorization.email/phone`, `user.passwordRecovery.email`; local PHP возвращает STATUS/ERRORS, TIMER, CODE_PUBLIC, OPEN_POPUP_AJAX или REDIRECT. Mobile accepted+reference недостаточен. Secret registration inputs нельзя повторять в URL, как делает старый action-reg.php72–79; нужен opaque challenge.
- OTP:6digit random_int; TTL10min, повтор>=60sec,лимиты identity/IP/session из ConfirmationCodes.php14–22. Source createNewCode сохраняет запись перед вызовом sender и не превращает sender result в строгий delivery result; wrapper обязан различать issued/sent/delivered/failed, а не обещать полученный код.
- CRM order: onSaleOrderSavedHandler→createDeal. Формы используют свои add* methods; это иной поток, не дополнительный order lead. Поле-в-поле expression/line карты каждого add* собраны в JSON, без конфигурационных значений. Local save и CRM delivery различать, supplier/partner source игнорирует nullable CRM response.
- 1С: order UID+document type→HTTP PDF→HL UF_LINK/UF_TYPE/UF_ORDER_ID. Existing read-only DocumentManifest не вызывает pull и не доказывает exchange; wrapper обязан проверить user/organization order ownership до выдачи документа.
- Checkout зависит от Region PRICE_CODE/STORE/delivery/payment и Sale component handlers. Авторитетный payment invoice constant **16** (`defines.php:108`), не13из старого комментария; Yandex courier ID7. Root ведёт точные checkout DTO и правила. Public source payment widget не делает все способы доступными всем пользователям.
- Delivery: product calculator registry Yandex/CDEK/Pickup; Dellin class отдельно. CDEK tariff139 не равен любому checkout tariff. GAR ID не доказывает serviceRegion/warehouse/transport-company price mapping.
- Source credentials/env/basic headers/webhook paths не включены в документы, не использованы. Новая интеграция требует свежей конфигурации владельца. HTTP allowlist/timeout/redirection/TLS/response validation нужно реализовать, отсутствующий adapter нельзя маркировать только внешним блокером.
