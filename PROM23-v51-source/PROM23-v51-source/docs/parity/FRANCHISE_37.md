# Франшиза 37 — текст и география сети

По последним правкам владельца:
- Заголовок «Что вы сможете продавать» и естественные пояснения товарных групп вместо канцелярских формулировок.
- Астана заменена на Алматы; добавлены Гудаута (Абхазия) и Луганск.
- Восемь действующих точек: Минск, Тюмень, Иркутск, Тбилиси, Алматы, Ереван, Гудаута, Луганск.
- Все маркеры одинакового активного цвета; выбор обозначается отдельной рамкой и доступным состоянием кнопки. Номера связывают карту со списком. Каждая карточка содержит статус «Работает».
- Близкие города разнесены выносными линиями. Координаты обозначают центры городов, не адреса магазинов. Список остаётся доступен без использования карты.

Изменены только три mobile-файла: FranchisePage.tsx, franchisePage.ts, franchiseNetwork.ts. Формы, маршруты каталога, соседние страницы и интеграции сохранены.

Координаты новых городов сверены с [картой Алматы](https://maps.apple.com/place?auid=6601066364435551693), [картой Гудауты](https://mapcarta.com/Gudauta) и [GeoNames Луганска](https://www.geonames.org/702658/luhansk.html). Статус действующих точек подтверждён владельцем в чате, а не выведен из географических источников.
