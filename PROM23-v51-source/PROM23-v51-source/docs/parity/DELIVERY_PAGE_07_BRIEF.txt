==================================================
1. ОБЯЗАТЕЛЬНОЕ ГЛОБАЛЬНОЕ DESIGN-РЕШЕНИЕ
==================================================

В проекте вводится постоянное правило:

НА ВСЕХ КОНТЕНТНЫХ И СЕРВИСНЫХ СТРАНИЦАХ ДОЛЖНА БЫТЬ ОСМЫСЛЕННАЯ АНИМАЦИЯ ПРИ ВЕРТИКАЛЬНОЙ ПРОКРУТКЕ.

Это обязательное правило проекта.

После выполнения этой страницы добавь его в:

docs/DECISIONS.md

как отдельный ACCEPTED ADR.

Правило:

- основной storytelling идёт ВНИЗ, а не горизонтально;
- элементы появляются по мере scroll;
- анимация помогает понимать структуру;
- она не должна быть декоративной ради эффекта;
- не должна тормозить чтение;
- не должна задерживать действие пользователя;
- обязателен Reduce Motion fallback.

Разрешённые паттерны:

- fade + translateY;
- sequential reveal;
- progressive connecting line;
- number/icon activation;
- subtle scale/opacity;
- parallax только очень умеренно и только там, где он действительно полезен.

Запрещено:

- тяжёлые 3D-эффекты;
- bounce;
- бесконечные декоративные циклы;
- горизонтальный scroll как основной storytelling;
- анимации, мешающие 60 FPS.

==================================================
57. PAGE SCROLL ANIMATION
==================================================

Это ОБЯЗАТЕЛЬНАЯ часть страницы.

Каждая крупная секция должна иметь собственный scroll-reveal pattern.

Пример:

Hero:
stagger.

Delivery cards:
stagger.

Способы:
vertical connecting line.

ПВЗ infographic:
step reveal.

ТК route:
route progression.

Стоимость:
icons reveal.

Кто оплачивает:
progress path.

Срок:
vertical logic flow.

Объект:
checklist reveal.

Warehouses:
cards reveal.

Buyer tiles:
stagger.

Не использовать один одинаковый fade для абсолютно всех блоков.

Анимация должна поддерживать смысл каждой секции.

- transform;
- intersection observer/native visibility mechanism.

Не анимировать тяжёлые layout properties без необходимости.

Target:
60 FPS.
