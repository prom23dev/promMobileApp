# Баннеры 23 — автоматическая смена и свайпы

Запрос владельца отменяет прежнее решение «без таймера». Все фотографии, тексты, градиенты и маршруты сохранены.

Реализовано:
- Смена трёх слайдов по кругу каждые 6 секунд.
- Свайп влево — следующий, вправо — предыдущий, с переходом через края.
- Только выраженный горизонтальный жест от 45 px переключает баннер. Вертикальные жесты продолжают прокрутку страницы.
- Жест, начатый на CTA, перелистывает без случайного перехода; обычное нажатие открывает прежний маршрут.
- Точки навигации сохранены; добавлена кнопка паузы/возобновления.
- Таймер приостанавливается при касании, наведении мыши, клавиатурном фокусе на CTA/точке, уходе с экрана, скрытии вкладки и неактивном приложении. После взаимодействия — новый полный интервал.
- При prefers-reduced-motion автосмена выключена по умолчанию; её можно включить явно. Ручное переключение доступно.

Файлы: HomeMarketplace.tsx и useBannerCarousel.ts. Mobile commit 03fad5a. Использован PanResponder для native; для web — DOM Touch Events с направленной обработкой и touch-action: pan-y. Первый вариант единого PanResponder конфликтовал с вертикальным RN Web ScrollView; сенсорная проверка выявила проблему до публикации, web-обработчик заменён.

TypeScript и экспорт web/iOS/Android PASS. 63 браузерные проверки на ширинах 320/390/768/1280 плюс 9 lifecycle-проверок локально PASS. Свайпы отправлены через Chrome DevTools Input.dispatchTouchEvent; таймер проверен через Playwright clock. Проверены оба направления, цикличность, пауза/возобновление, точки, вертикальная прокрутка, свайп с CTA, нажатие CTA, reduced motion, hover/focus, скрытая вкладка, удержание пальца, возврат с другого экрана. JS-ошибок нет. Мобильный скриншот визуально проверен. Физический iPhone/Android не использовался.
