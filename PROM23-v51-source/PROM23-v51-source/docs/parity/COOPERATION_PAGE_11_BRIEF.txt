==================================================
4. ОБЯЗАТЕЛЬНАЯ SCROLL-АНИМАЦИЯ
==================================================

На этой странице обязательно использовать осмысленную анимацию при вертикальной прокрутке.

Это не декоративная опция.

Каждая крупная секция должна иметь свой reveal-паттерн:

Hero:
- eyebrow;
- H1;
- intro;
- затем направления с небольшим stagger.

Направления:
- последовательное появление;
- icon activation;
- subtle translateY + opacity.

B2B:
- преимущества появляются последовательно;
- линия процесса/связи может дорисовываться вниз.

Производство:
- visual + параметры заказа появляются по мере scroll;
- можно использовать технологическую вертикальную линию.

Поставщики / Франшиза:
- спокойный reveal.

«Промышленник» в работе:
- факты активируются при скролле;
- вертикальная линия / capability spine постепенно проходит через блок.

Reduce Motion обязателен.

Не использовать:
- bounce;
- тяжёлые 3D-эффекты;
- бесконечную animation;
- горизонтальный storytelling;
- эффекты, тормозящие scroll.
