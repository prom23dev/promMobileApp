# Гарантия 29

## План и границы
Новая редакция /pages/warranty по приложенному тексту владельца. Светлая служебная страница в системе доставки/сотрудничества: ink #202338, brand #3D4471, accent #D93916, white #FFFFFF, pale #EDF0F7, peach #FFF0E9. Системный шрифт: главный заголовок 29/36, заголовки 24/30, основной текст 15/23, подписи 12/18. Характерный элемент — схема пяти шагов обращения: горизонтальная на широком экране и вертикальная на телефоне.

Структура: помощь и главная кнопка → где найти гарантию → пять шагов → отдельные условия для личных/корпоративных покупок → сервис и производители → подготовка/история обращения → ссылка на возврат → помощь/покупателю. Юридические подробности доступны в раскрытиях. Повторные призывы объединены. Редакторские указания из исходника не публикуются. Не добавлять единый срок гарантии для каталога и автоматические основания отказа.

Главная кнопка «Гарантийный случай / Запросить гарантийное обслуживание» открывает существующую форму appeal с назначением warranty: отдельные заголовок/пояснение и редактируемый текст обращения, без выдуманных идентификаторов тем. Форма по заказу с приложениями остаётся доступна через заказ; общий вопрос не получает фиктивного загрузчика. История — /service?kind=appeal. Покупательский контекст меняется только при переходе к действию, а не при чтении вкладок. Все ограничения, согласия и серверная отправка существующих форм сохраняются.

## Проверка содержания
Текст владельца — основной источник. Проверены статьи 18–20 Закона РФ о защите прав потребителей и 470, 471, 476 ГК РФ (КонсультантПлюс, 17.09.2026). В исходнике ссылка для ответственности продавца ошибочно вела на статью 470: список оснований дополнен статьёй 476, для потребителя — 18. Указание о тяжёлом товаре уточнено без абсолютного запрета самостоятельной доставки и с правом на возмещение в предусмотренных случаях. Срок ремонта не представлен универсальным обещанием «45 дней»; сохранено различие минимально необходимого и письменно согласованного срока. Ссылки на статьи доступны в странице. Утверждение «механическое повреждение — гарантии нет» не используется как правило.
