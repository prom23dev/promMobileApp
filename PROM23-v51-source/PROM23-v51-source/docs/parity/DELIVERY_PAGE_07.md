## SCROLL ANIMATIONS

Вертикальное появление секций, активация линий маршрута, последовательное появление иконок. Opacity/transform, IntersectionObserver на web и ограниченное измерение видимости на native. Reduce Motion показывает содержимое без движения. Глобальное правило записано в ADR-033 со статусом ACCEPTED; это не визуальная приёмка страницы.

Публичный прогон выявил React #185 при смене Reduce Motion. Отдельный повтор воспроизвёл ошибку восемь раз. Причина связана с отдельными подписками каждого потребителя и удалением обработчиков в React Native Web через строковый ключ функции. useReducedMotion переведён на один общий источник состояния с useSyncExternalStore и корректной отпиской matchMedia. Первичный неуспешный прогон сохранён. После исправления локально прошли восемь повторных циклов без ошибок; финальный общий прогон также прошёл 188/188.
