## Корзина, география и формы

Корзина: проверены add1, badge1, один переход в корзину, увеличение до2 и сумма26900₽, избранное/сравнение, сохранение товара после выбора места. Guest→authorized merge, корпоративная цена и документы не приняты без реального backend.

География: ГАР/ФИАС идентификатор и тип населённого пункта отделены от service region/склада/адреса. «Динская» выбирается как станица; arbitrary query не сохраняется. После выбора показано уведомление, корзина сохранена. Наличие остаётся unknown; это не успешный пересчёт реальной доставки/складов. Domain/CAS/nullable contracts покрыты серверными тестами. См. [backend register](../audit/backend-master5-clauses.json).

Формы:102 исходных вхождения сопоставлены с68 mobile definitions, включая aliases и динамические зависимости. [Source inventory](../audit/forms-parity.md) сохраняет names/required/files/consents/handlers. В браузере проверены профильные входы, ошибки обязательных полей/неверного телефона/согласия, два режима и выбор файлов. Положительная отправка каждой формы, duplicate/timeout каждого реального handler,11 DB-зависимых ресурсов и CRM/1С результат — **BLOCKED/UNVERIFIED**, не успешная parity. [Функции](../audit/function-parity.md), [страницы](../audit/web-mobile-parity.md).

## Ограничения и честность доказательств

- Реальные авторизация, организация, заказы, оплата, доставка, начисление баллов, документы, отзывы, возвраты и ERP/CRM требуют подключения программистами. Синтетический успех не показывался.
- Expo Web viewport/reduced motion и компиляция JS не подтверждают pinch/VoiceOver/TalkBack/Dynamic Type, safe areas и60fps на нативных устройствах. Подписанных/установленных IPA/AAB/APK не проверяли. [Технический release](technical-release-v9.md).
- Полные правовые редакции возврата/согласий и store questionnaires требуют финального утверждения; обнаруженные исходные правила не выданы за автоматически соответствующие закону. [Правовые findings](../audit/content-v9-legal-findings.md).
- Массовые412 reload вызвали76 промежуточных bootstrap rate-limit состояний. После нормального темпа все соответствующие экраны подтверждены; два повтора попали в объявленный export HTTP503 и также перепроверены. Raw сохранены, ограничения не обходились. Общий bootstrap error временно заменяет shell; это не проверка устойчивого offline режима.
- Geo-тест сначала неверно прочитал envelope `.items` вместо `.data.items`. Исправлен только тест; отдельный повтор прошёл. Исходный результат сохранён в `qa-v9-final-supplement-initial.json`.
- Полный ручной клик по каждому handler исходного сайта не выполнен. Source audit, все mobile routes и выбранные критические цепочки не названы полным исходным click-through.

Защищённый `zavod-antibpla.ru` QA-подзадача не меняла. Root отдельно подтвердил неизменность82 файлов, процессов иHTTP200 до/после изолированного релиза; [deployment verification](../deployment-v9-verification.json). DNS и общие сервисы не изменялись.
