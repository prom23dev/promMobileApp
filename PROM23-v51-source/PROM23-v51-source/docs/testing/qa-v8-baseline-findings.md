## Реальный дефект, переданный в основную задачу

**V8-UX-01 · каталог / browser history.** Выбор дочернего раздела менял только component state; URL не содержал новый section, reload не гарантировал возврат в выбранный раздел, системный Back не проходил по уровням. Breadcrumb «Леса» и «Все разделы» работали. Подтверждено исходником CatalogScreen.choose/root и сценарием после выбора первого дочернего раздела. Скрин `../qa-v8-failure-6.png` показывает доступный breadcrumb и отсутствие общей кнопки «Назад» у tab каталога. Root сообщил исправление через router.push + section URL; **финальный кандидат с этой правкой ещё надо прогнать**.

Остальные три исходных FAIL не объявлены дефектами продукта: общий text selector нашёл несколько надписей наличия; getByLabel выбрал скрытый предыдущий экран Expo stack; тест ожидал универсальное «Назад» внутри tab каталога. Селекторы ограничены активным экраном, проверена реальная breadcrumb/browser navigation. Первичные отчёты сохранены, а успешные повторные результаты приведены отдельно.
