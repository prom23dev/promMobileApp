## Исправленные проблемы и след проверки

**V8-UX-01 закрыт в финальной сборке.** Ранее Expo Tabs заменял browser history при изменении section query: history.length не рос, а после reload Back уходил за пределы каталога. Это подтверждено [probe JSON](qa-v8-history-scroll-probe.json). Root перенёс выбранные разделы в Stack; итоговый сценарий проверил реальные URL, reload и оба способа возврата.

Прокрутка блока выгод в первом прогоне не прошла из-за координат/ожидания harness. Повторный probe с wheel по центру фактического home-feed достиг buyer/business при390 и844, а полный финальный прогон подтвердил все пять размеров. Виртуализация не менялась ради прохождения теста. Старая цена/скидка дополнительно проверены селектором активного Expo screen: скрытый предыдущий экран не должен попадать в проверку.

Исторические отчёты [первого кандидата](qa-v8-baseline-report.json), [кандидата21b](qa-v8-candidate-21b-report.json) и [разбор baseline](qa-v8-baseline-findings.md) сохранены, но не заменяют результат финального SHA. Промежуточный ограниченный запуск остановился на защитной проверке смены entry; этот останов не считается дефектом приложения.

## Ограничения

Изолированный headless Chrome, новый профиль; использованы только собственные preview sessions/actions/location. Ни реальных звонков, ни почты, CRM, платежей, возвратов или подписок не выполнялось. Fixture responses применялись только для двух явно помеченных UI ветвей; серверный `allowTestFixtureOperations` не включался.

Частично видимые крайние категории в горизонтальной ленте допустимы как указание на прокрутку; они не являются document overflow. Проверка24 CSSpx — ограниченная browser-проверка целей, не утверждение полного WCAG или соблюдения всех нативных touch targets. Native iOS/Android, VoiceOver/TalkBack, Dynamic Type, signing, магазины и реальные интеграции проверяются отдельно. Отсутствие staging/аккаунтов не блокировало нынешнюю source/preview итерацию.

Публичное размещение этого SHA — ответственность отдельной deployment-проверки основной задачи. Эта QA-подзадача сервером и DNS не управляла и боевой сайт `zavod-antibpla.ru` не изменяла.
