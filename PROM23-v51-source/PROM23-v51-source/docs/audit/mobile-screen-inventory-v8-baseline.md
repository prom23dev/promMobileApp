## Текущая Foundation — отдельная архитектурная запись

После фиксации V8 registry root изменил AppShell:5вкладок `(home)/(search)/(shopping)/(saved)/(user)`, у каждой retained Stack и thin route reexports обычных экранов. Public URL-контракт сохранён. Поэтому количество физических файлов больше количества пользовательских экранов; это не дубликаты меню. Checkout остаётся root immersive, auth скрывает nav, fallback ещё требует решения.

Foundation baseline прошёл те же412 URL; независимый4-сценарный gate подтверждает PDP→Cart1tap, ContactsBack, stack/scroll retention и childReload/Back. Это **не** проверка всех возможных group-qualified deep links и не нативная приёмка. На окончательном export нужен повтор route test с явным `expectBottomNav` и immersive gallery/keyboard checks.

LocationPicker — модальный state, а не самостоятельный route: screenshot [опубликованная V8](v9-before/published/location.png). При открытом modal нижняя nav может быть недоступна фокусу; после закрытия должна возвращаться.
