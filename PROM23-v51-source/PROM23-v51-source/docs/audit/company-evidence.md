Дата проверки: 11.09.2026. Сопоставлены active PHP/CMS bindings и публичные `/about/`, `/awards/`, `/brands/`, `/business/`, `/vendor/`. Это подтверждение того, что именно заявлено корпоративным источником, а не независимая проверка экспортных деклараций/реестров премий. Реальные операции не выполнялись, UI не менялся.

B2C и B2B равнозначно важны. Производство, история, награды и экспорт могут быть общим доказательным слоем для обоих путей — без превращения магазина в корпоративный портал.

## Награды: что можно утверждать

Публичный реестр содержит 9 записей. Это **не 9 независимых наград**: диплом и статуэтка могут относиться к одной победе; часть наград названа в честь конкретного человека. В PHP год берётся из `ACTIVE_FROM` (awards/index.php:69). Поэтому год в интерфейсе реестра подтверждён, но не автоматически равен году на дипломе. Полноразмерные читаемые документы для независимого чтения даты в этом source не обнаружены: runtime PNG имеют 86×123px. Их нельзя растягивать как якобы качественные сканы сертификатов.

## Экспорт — самостоятельное доказательство

На `/about/` прямо сказано об экспорте в страны СНГ, Азии и Африки. Это сильнее предположения по карте филиалов. В истории 2023 отдельно стоит «Экспорт в 20+ стран»; его допустимо показывать только как датированную историческую запись. Для общего блока предпочтительнее география без текущего числового счётчика. Не перечислять конкретные страны, объём или долю экспорта без отдельного source.

## Не использовать как текущий проверенный факт

- **Производим с2008**: Timeline:2008основание,2021строительство,2022перваяочередь.
- **16 лет на рынке**: Старая относительная цифра source в2026; использовать абсолютный2008.
- **10+наград /9наград**: Реестр9 записей содержитдипломы/статуэткиоднихпремий; достоверноеподсчитываниеуникальныхнаграднеподтверждено.
- **10 000+проектов /50 000+клиентов**: Маркетинговые counters source без даты/методики; не нужны для безопасного trustblock.
- **Производство12000м²**: 12000м² — Краснодарский склад.
- **Экспорт в каждую страну, где указан филиал**: Список франшиз/складов сам по себе не доказательствоэкспорта.
- **Все товары сертифицированы**: Маркетинговыйgenericтекст не подтверждает product-level сертификаты; awardsреестр в основном дипломы, не сертификатысоответствия.
- **Fubag/Inforce/Ryobi — наши собственные бренды**: Brands page смешиваетперепродажу и собственные марки; ownershipнеподтверждён.
- **Компания построила Москва-Сити/КРКОктябрь**: Sourceкейсы о поставленномоборудовании, нестроительствезданиякомпанией.
- **Отзывы с [название компании]**: Очевидныеplaceholderнаживыхabout/vendor; исключить.
- **Наш роботизированный станокØ42**: Конкретнаямашина/владение/типоперациине подтверждены.

## Рекомендация для реализации shared trust block

Заголовок: **«Промышленник: производство и поставки»**.

Четыре ясных факта: «На рынке с 2008 года» → история; «Собственное производство» → фото/процесс; «Награды „Экспортер года“» → точный реестр; «Экспорт в СНГ, Азию и Африку» → подтверждённый раздел о компании. Один реальный предметный кадр и короткие ссылки дадут больше доверия, чем недатированные счётчики. Для B2C рядом сохраняется выбор товара/корзина, для B2B — потребность/файл/предложение. Не добавлять CTA-копии каждой формы.

Machine-readable curated source: `docs/audit/company-evidence.json`. Raw public DOM evidence: `company-source-runtime.json`, `public-rich-content.json`. Последующее подключение к CMS должно сохранить ownership/date/source status полей; исторические данные не превращать в current counters.
