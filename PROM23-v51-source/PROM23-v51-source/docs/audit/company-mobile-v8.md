# Компания, производство и бизнес: мобильная реализация V8

11.09.2026. Реализация из корпоративных источников; не независимая проверка реестров премий и не проверка действующих CRM/1С операций.

## Владение и API

- `mobile/src/ui/CompanyTrust.tsx`: `CompanyTrust({variant?: 'compact'|'expanded'})`, compact по умолчанию. Общий блок для B2C/B2B; повторная фотография цеха убрана из compact после визуальной критики, поскольку уже есть в hero. Экспорт `CompanyDisclosure` используется для доступных раскрытий.
- `mobile/src/ui/CompanyTopic.tsx`: `CompanyTopic({topic:'business'|'production'})`.
- `mobile/src/content/companyContent.ts`: безопасно курированные факты, история, награды, условия, 20 вопросов в четырёх темах и 6 этапов производства.
- `InformationScreen.tsx`: подключает богатую подачу business/production, заменяя прежние текстовые карточки и дублирующие CTA. Delivery/payment/contacts сохранены. Контакты используют `location.settlement.name`; просмотр другого филиала не меняет населённый пункт доставки.
- `sitePages.ts`: исправлены две смысловые неточности старого импорта about/brands (основание ≠ запуск производства; перепродаваемые марки ≠ собственные).

## Что сознательно не превращено в утверждения

- Нет «производим с 2008», 12 000 м² цеха, текущего количества клиентов/проектов/наград/стран.
- Дипломы и статуэтки одной победы не считаются разными наградами. CMS ACTIVE_FROM не выводится как дата диплома.
- Награды компании не заменяют сертификаты на изделие; низкокачественные 86×123px превью не растянуты в крупные сканы.
- Не перенесены placeholder отзывы `[название компании]` и дублирующиеся нетематические ответы vendor FAQ.
- Не заявлено владение роботизированным станком для Ø42; используются только реальные корпоративные медиа.
- Не имитируются успешная заявка, резерв, ЭДО или действующее начисление бонусов.
