# V7 — независимая проверка первого экспорта

11.09.2026, `http://127.0.0.1:8087/`, isolated Chromium/Chrome, Expo Web. **11 из 12 браузерных сценариев прошли**. Пять новых unit tests спецификации прошли. Нативная проверка остаётся BLOCKED по `testing.md`; выводы не распространяются на App Store/native или подключённые платежи.

Применены adversarial-ux-test и accessibility audit. Персона для проверки: снабженец 56 лет, хочет передать список оборудования и разобраться с получением; нет терпения к потере списка и непонятному возврату. Это моделирование сценария, не исследование с настоящим респондентом. Использован локальный экспорт по прямому заданию, а не production или dev hot reload.

## Что прошло

- Главная/популярные/B2B на 320, 390, 430, 768 и 844×390: горизонтального document overflow, безымянных видимых controls и целей меньше 24 CSS px не найдено. Последняя граница не заменяет native 44pt/48dp. Частично видимая следующая категория — намеренный горизонтальный ряд, не дефект страницы.
- Звонок/контакты доступны на первом экране 320/390; телефон проверен статически, без фактического вызова; контакты и Back работают.
- Hero переключает фото/назначение ссылки; проект/производство открываются и возвращаются. Популярные расширяются с 6 до 10 без дублирования.
- Поиск остаётся вводом, история сохраняется после reload, удаляется; меню и Back сохраняют поисковый запрос.
- B2B radio меняет предложение и нужный путь. На 320 выбранный текст остаётся внутри control. Быстрый заказ блокирует нулевое количество, сохраняет известный и неизвестный SKU и введённые количества; согласия выключены.
- Доставка/оплата/кабинет раскрывают условия, ведут в нужные разделы и возвращаются. City modal удерживает фокус; Escape и действие в landscape доступны.
- Нет JS page errors и заблокированных попыток внешней записи; разрешались только local sessions/actions POST. Формы, платежи и звонки не отправлялись. Reduced-motion preference включена; полноценная native motion-приёмка отдельно.
