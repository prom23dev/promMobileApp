# Размещение тестового приложения без домена

Размещено 11.09.2026 на существующем сервере 159.253.19.172 отдельной службой. Адрес теста: **http://159.253.19.172:18087/**. Пользователь отменил привязку pro159.ru. DNS не изменялся.

## Изоляция от zavod-antibpla.ru

- Отдельный каталог `/var/www/fastuser/data/prom23-mobile-preview/`, вне сайтов `www/`.
- Пользовательская служба `prom23-preview.service`, существующий Node 24.13.0.
- Порт 18087 — тестовый интерфейс; API 18090 доступен только через loopback. Не используются 80/443 и виртуальные хосты действующего сайта.
- nginx, Apache, MariaDB, WordPress, DNS и firewall не перенастраивались и не перезапускались.
- `PrivateUsers=yes`, `ProtectSystem=strict`, `InaccessiblePaths=/var/www/fastuser/data/www`: процесс теста не может открыть каталог боевого сайта. До запуска эффект проверен отдельной одноразовой службой.
- RAM 256 MiB, Node heap 128 MiB, CPU 25% одного ядра, 32 задачи, низкий приоритет, ограничение одного файла 64 MiB. SQLite — 32 MiB основного файла плюс небольшой WAL/SHM, ограниченное число сессий/заказов/расчётов. Файлы БД доступны только владельцу.
- Готовые файлы собираются на компьютере; на сервере нет npm-install и сборки приложения. Одна поставка около 4,7 MiB в архиве.

На момент проверки основной сайт вернул HTTP 200. SHA-256 всех файлов активной темы совпали до/после размещения; PID и время запуска nginx/Apache/MariaDB также не изменились. Доказательства: `docs/deployment-v2-verification.json`.

## Доступ и ограничения

SSH-доступ был получен из истории задачи «БПЛА» по разрешению пользователя. Пароли/ключи не включены в проект или архив.

Первоначально планировался приватный SSH-туннель, но хостинг отказал с `administratively prohibited`. Туннель закрыт, запрет не обходился. После этого интерфейс вынесен на отдельный доступный TCP-порт по IP; API остаётся на loopback. Firewall не менялся.

Это **тестовый HTTP-стенд** без домена и сертификата. Ввод реальных персональных данных, платежи и боевые аккаунты здесь не предусмотрены. Непрозрачный токен идентифицирует только тестовую сессию и её корзины. Это не production-аутентификация и не подтверждение полномочий юрлица.

Прокси проверяет точный Host, устанавливает noindex/CSP/защитные заголовки, ограничивает API-запросы и обслуживает только `mobile/dist`. API проверяет Origin, токен тестовой сессии, тела запросов, expectedContext и принадлежность заказа. Создание обращений и возвратов заблокировано до подключения справочников и правил действующего сайта.

Предпросмотр использует React Native Web. Сборка JavaScript для iOS/Android проверена экспортом, но это не APK/AAB/IPA, не установленное нативное приложение и не допуск магазина.

## Запуск, обновление, откат

Включены только автозапуск тестовой пользовательской службы и Linger для fastuser. Стенд не зависит от открытой вкладки/SSH-сеанса. Сервер не перезагружался; фактическое восстановление после перезагрузки не проверялось.

```sh
ssh fastuser@159.253.19.172 systemctl --user status prom23-preview.service
ssh fastuser@159.253.19.172 systemctl --user stop prom23-preview.service
ssh fastuser@159.253.19.172 systemctl --user start prom23-preview.service
```

Новая сборка распаковывается в собственный `releases/<id>`, сверяется по SHA-256, затем атомарно переключается только `current` и перезапускается только `prom23-preview.service`. Каталог `state` остаётся отдельным. Для отката вернуть `current` на предыдущую работавшую сборку. Не использовать команды restart nginx/apache/mysql и не менять `www/`.

Release 01 не запускался из-за кавычек в переменной systemd; исправлено в 02. Release 03 добавил доступ по IP. Release 04 содержит финальную русскую оболочку предпросмотра. Предыдущие каталоги сохранены отдельно; никаких файлов боевого сайта при исправлениях не менялось.
