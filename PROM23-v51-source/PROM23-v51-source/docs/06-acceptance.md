# Приёмка полного приложения

Статус на 11.09.2026: **релиз не готов**. Здесь задана проверка будущей полной версии. Демо-проверки первого среза записываются отдельно в `07-validation.md`.

## Последовательность реализации

1. Воспроизводимое тестовое окружение: Bitrix/БД/медиа, 2 физлица, 2 организации с несколькими ролями, sandbox оплаты/доставки/кассы. Зафиксировать функциональность сайта по матрице `02-feature-parity.md`.
2. Исправить серверные блокеры из аудита, определить модель членства в организациях, юридические основания хранения/удаления и поток платежей.
3. Реализовать и проверить мобильный API: авторизация/сессии, публичный каталог, контекстные корзины, серверные котировки, заказ/оплата, профили/организации.
4. Подключить экраны к API, реализовать документы/ЭДО, возвраты, обращения, отзывы, заявки, калькуляторы, уведомления и вспомогательные страницы. Нельзя исключать функции как «второстепенные» без решения владельца.
5. Проверить все строки матрицы на реальном сервере, соответствие цен/остатков и обмен с 1С, конкурентные сценарии сайта и приложения.
6. Device QA, доступность и замеры производительности; закрыть дефекты; юридические тексты и данные магазинов на основе фактического SDK/трафика.
7. Подписанные сборки, TestFlight/Google Play internal testing, разрешённый тестовый доступ модерации; финальная проверка перед отправкой.

## Критические тесты

| Группа | Сценарии |
|---|---|
| Авторизация | Верный/неверный/истёкший/уже использованный код; rate limit; ротация refresh; отзыв сессии; украденный старый refresh; выход офлайн; отсутствие токенов в логах |
| Организации | Пользователь А не видит Б; компания А не видит Б при подмене ID; знание ИНН не даёт доступ; отозванный сотрудник теряет права; роли заказчика/бухгалтера/администратора согласно правилам бизнеса |
| Смена контекста | Отмена старых запросов; ответ старой компании не появляется после смены; цены, адреса, документы и корзины не смешиваются; переключение во время оплаты |
| Каталог | Те же SKU/варианты/категории и цены, фильтры по свойствам, поиск по артикулу, пагинация без дублей, изображения, регион и остатки |
| Корзина | Кратность, единицы, комплектность, скидки/промокод, недоступный товар, изменение цены, конкурентное изменение на сайте, merge гостя после входа |
| Заказ | Двойное нажатие, retry после таймаута, истёкшая котировка, отсутствующий остаток, изменившаяся доставка/цена; ровно один подтверждённый заказ |
| Платёж/СБП | Успех, отказ, отмена, возврат из банка, потеря сети, закрытие приложения, дубликаты/поддельная подпись webhook, неверная сумма/валюта, платёж после отмены заказа |
| ККТ/документы | Оплата/предоплата/зачёт/возврат, правильные налоговые поля и контакты; доступ только владельцу; истечение download URL; документы 1С совпадают с заказом |
| Возврат | Частичный/полный, качество/недостаток, комплект, доставка, сроки и статусы, повтор запроса, подтверждение возврата денег |
| Удаление | Запрос из приложения и веба; re-auth; отзыв сессий; удаление/обезличивание по основаниям; объяснение обязательного хранения; отсутствие доступа к удалённому профилю |
| UGC/поддержка | Авторство, вложения, тип/размер/вирусы файлов, модерация/жалоба/блокировка, недопустимый контент, история обращений |
| Уведомления | Отказ в разрешении не мешает покупке; отключение рекламы; выход удаляет привязку токена; push не раскрывает сведения на экране блокировки |
| Устройства | Физические iPhone и Android, маленький экран, крупный шрифт, VoiceOver/TalkBack, клавиатура, safe area, системный Back, deep links, 16 KB Android, IPv6/NAT64 |
| Сеть | Offline, медленная сеть, таймаут, 401/403/409/429/500, повтор входа, отсутствие «бесконечного спиннера», восстановление после перезапуска |

## Требуемые решения владельца

- Тестовый URL и доступ к тестовым ролям; адрес `prom.myfast.space` встречается в контексте проекта, но пользователем как окружение для этой работы не подтверждён.
- Разрешение/способ доработки backend, контакт действующего разработчика, версия и лицензия Bitrix.
- Название/издатель/страны, аккаунты Apple Developer и Play Console; идентификаторы пакетов и подпись после подтверждения владельца.
- Полный набор оплат, доставка, 1С, ЭДО, касса/ОФД, хостинг и регион данных. Тестовые ключи — в защищённом хранилище, не в переписке и не в приложении.
- Правила доступа представителей организации: приглашение/верификация, роли, согласование заказа, счета/НДС, отсрочка, грузополучатели.
- Утверждённые оферты/условия, оператор ПД, возвраты, поддержка и ответственный за UGC.

Сроки полной разработки и стоимости инфраструктуры оцениваются после подтверждения этих зависимостей. Выпуск и обработка реальных заказов первым демо-срезом не предусмотрены.
