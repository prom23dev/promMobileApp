# UX47 — компактная общая шапка

Требование владельца: поиск рядом с городом, расширить область названия; переключатель «Для себя / Для бизнеса» и организацию разместить ниже компактно и убрать из закреплённой области при прокрутке.

## Изменения

- Общий ShopHeader: логотип/меню/уведомления/телефон и строка город + поиск. Город занимает42% строки, максимум240px; название переносится на две строки. На320px подсказка поиска — «Поиск».
- Общий PageScroll переносит BuyerContextSwitch в начало основного ScrollView/FlatList. Блок естественно прокручивается вместе со страницей, не меняя высоту шапки. Режим и организация сохраняются.
- Сохранены обработчики прокрутки, ref, ListHeaderComponent, пагинация, поиск, модальные окна и keyboard options. Вторичные горизонтальные списки не получают дополнительные переключатели.
- Пустое сравнение, отсутствующие товар/раздел/публикация и404 сохраняют доступ к выбору покупателя. Удалён лишний повтор переключателя в уведомлениях.
- Тексты о назначении покупки,44px зоны нажатия, бизнес-корзина, оплата по счёту, согласия и юридические документы сохранены.
