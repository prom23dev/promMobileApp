# Мобильный API: проект контракта

Версия 0.1, 11.09.2026. Сервер **ещё не реализован**. Пути ниже — проект нового контракта, а не существующие рабочие endpoints сайта. Адаптер пишет разработчик Bitrix после проверки базы, прав, HL-блоков и интеграций. Не открывать старые AJAX-обработчики напрямую в мобильный клиент.

Базовый путь `/mobile/v1`, HTTPS. JSON, UTF-8. Успешный ответ `{data, meta:{requestId}}`, ошибка `{error:{code,message,fieldErrors?},meta:{requestId}}`. ID — непрозрачные строки; цены и суммы — целые копейки, валюта RUB; даты — ISO 8601 UTC. Request ID не содержит ПД. В клиенте ответы валидируются схемами на runtime. Версии SDK, ID инфоблоков и провайдерские ключи не являются частью публичного контракта.

## Авторизация, полномочия и повтор запросов

`Authorization: Bearer <access-token>`. Refresh token хранится на устройстве в Keychain/Keystore и ротируется сервером при каждом использовании; сервер хранит его хеш. Веб-превью не хранит настоящие токены. Cookie сайта не является мобильной авторизацией. Сроки действия, rate limits и правила step-up проверки задаёт сервер.

`X-Organization-Id` запрашивает контекст организации, но **не даёт** полномочий: сервер проверяет действующее членство, роль, верификацию и доступ к конкретному объекту на каждом запросе. Нельзя доверять `userId`, ИНН или цене от клиента. Отсутствие заголовка означает личный контекст. Доступные компании выдаёт `/me/organizations`.

`Idempotency-Key` обязателен для создания заказа, платёжной сессии, возврата и повторяемых финансово значимых действий. Сервер сохраняет ключ с пользователем, контекстом, хешем тела, состоянием и ответом атомарно. Повтор того же тела возвращает тот же результат; другое тело с тем же ключом — 409. После сетевого таймаута клиент запрашивает результат по тому же ключу; не генерирует новый автоматически.

HTTP: 400 валидация, 401 сессия, 403 права, 404 отсутствует/скрытый чужой ресурс, 409 конфликт/устаревшая цена, 410 истёкшая котировка, 422 бизнес-ограничение, 429 лимит с Retry-After, 5xx временная ошибка. Детали PHP/SQL никогда не возвращаются клиенту.

## Карта ресурсов

| Методы и путь | Содержание / критерий |
|---|---|
| GET `/bootstrap` | Версии правил, доступные города и способы входа, feature flags; без секретов |
| GET `/categories`, `/brands`, `/catalog/collections` | Структура каталога, бренды, подборки; пагинация где нужна |
| GET `/products?q=&category=&filters=&sort=&cursor=&limit=` | Каталог, фасеты, остатки/цены для региона и контекста; `limit ≤ 50`, opaque cursor |
| GET `/products/{id}` | SKU, галерея с размерами, варианты, документы, характеристики, совместимые товары, единицы продажи, ограничения |
| GET `/products/{id}/reviews`, `/questions` | Опубликованные отзывы/вопросы; модерация и пагинация |
| POST `/calculators/scaffolding/quote` | Расчёт комплекта лесов; спецификация/цена только с сервера |
| POST `/auth/challenges` | Телефон в E.164, назначение; ответ challengeId/TTL/retryAfter без раскрытия существования пользователя |
| POST `/auth/challenges/{id}/verify` | Проверка кода, одноразовость, лимит попыток; создание/вход согласно согласию и правилам |
| POST `/auth/refresh`, `/auth/logout` | Ротация/отзыв токенов; повтор украденного refresh отзывает семейство сессий |
| GET `/me`, PATCH `/me` | Разрешённые поля профиля, верификация изменения телефона/email отдельным challenge |
| GET `/me/sessions`, DELETE `/me/sessions/{id}` | Управление устройствами; подтверждённый отзыв |
| GET/POST `/me/deletion-requests` | Статус/запуск удаления; re-auth, категории/сроки обязательного хранения, доступная веб-страница запроса |
| GET/PUT/DELETE `/me/favorites/{productId}` | Список/добавление/удаление избранного; merge гостевого списка при входе |
| GET/PUT/DELETE `/me/comparison/{productId}` | Сравнение совместимых характеристик; серверные ограничения |
| GET/POST/DELETE `/me/waitlist/{productId}` | Лист ожидания с основанием уведомления и отпиской |
| GET/POST `/me/addresses`, PATCH/DELETE `/me/addresses/{id}` | Владение/орг-контекст проверяются; адрес, получатель, основной адрес |
| GET `/me/organizations` | Только компании с подтверждённым доступом пользователя |
| GET `/organizations/lookup?inn=` | Только общедоступные реквизиты; никакого автоматического присоединения к существующей компании |
| POST `/organization-access-requests` | Запрос представительства/приглашение; верификация и одобрение уполномоченным лицом |
| GET/PATCH `/organizations/{id}` | Реквизиты, грузополучатели; изменение по роли и аудиту |
| GET/POST `/organizations/{id}/verification` | Статус и документы проверки представительства |
| GET/PATCH `/organizations/{id}/edo` | Оператор, идентификатор, подключение и статусы ЭДО |
| GET `/cart`, PUT/DELETE `/cart/items/{sku}` | Раздельная корзина контекста; допустимые количества/кратность/комплектность на сервере |
| PUT/DELETE `/cart/coupon` | Валидность и совместимость скидок проверяет сервер |
| POST `/cart/merge` | Явный merge гостевой корзины, конфликты по SKU и количествам возвращаются в ответе |
| POST `/delivery/quotes`, GET `/delivery/pickup-points` | Регион, состав/вес/габариты, адрес; тариф, сроки, TTL, ограничения. Геокодер через сервер |
| POST `/checkout/quotes` | Фиксирует согласованный состав, цены, НДС, получателя, доставку, условия B2C/B2B |
| POST `/orders` | Только действующая котировка, необходимые согласия/версия условий, идемпотентность; атомарный пересчёт/резерв |
| GET `/orders`, `/orders/{id}` | История, активные/завершённые, состав и статусы; проверка владельца/членства |
| POST `/orders/{id}/repeat` | Текущая цена/остаток, а не прежняя цена; предупреждение об отсутствующих позициях |
| POST `/orders/{id}/cancellation` | Допустимый статус/роль, идемпотентность, обновление резерва/возврат оплаты |
| POST `/orders/{id}/payment-sessions` | URL/SDK token выбранного PSP или СБП; допустимые домены возврата и сумма с сервера |
| GET `/payments/{id}` | Доверенный статус после подтверждения провайдером |
| GET `/me/payment-methods`, POST `/me/payment-method-sessions`, DELETE `/me/payment-methods/{id}` | Только токены PSP, masked PAN/last4. Никогда CVV/PAN в API магазина |
| GET `/documents`, `/documents/{id}/download` | Счета, УПД, договоры, сверка — состав уточняется по реальной БД; приватные ссылки с TTL |
| GET/POST `/returns`, GET `/returns/{id}` | Частичный/полный возврат по конкретным позициям, причины, доказательства, статусы, возврат денег |
| GET/POST `/appeals`, GET `/appeals/{id}`, POST `/appeals/{id}/messages` | Обращения/претензии, файлы через ограниченные upload sessions, поддержка/оценка |
| POST/PATCH/DELETE `/reviews/{id}`, `/questions/{id}` | Собственные материалы, проверка покупки при необходимости, модерация до публикации |
| POST `/content-reports`, POST/DELETE `/blocked-users/{id}` | Жалобы на UGC, блокировка авторов и инструменты модерации согласно правилам магазинов |
| GET/PATCH/DELETE `/notifications/{id}` | Центр уведомлений, прочтение/удаление |
| GET/PATCH `/notification-preferences` | Сервисные и рекламные категории разделены; opt-in на рекламу, отзыв |
| POST/DELETE `/devices/{id}/push-token` | Привязка к текущей сессии, платформе; очистка при logout/отзыве |
| GET `/consents`, POST `/consent-events` | Неизменяемая история с purpose, version, timestamp, основанием и отзывом; не общая галочка |
| GET `/legal/{document}`, `/content/{slug}`, `/contacts`, `/stores` | Политика, условия/оферта, возвраты, аренда, лизинг, бизнес, поставщики, блог и прочие страницы |
| POST `/service-requests` | Звонок, аренда, лизинг, один клик, дешевле, консультация, документы, экскурсия, сотрудничество — валидируемые типы |

Некоторые строки группируют операции, окончательное OpenAPI разносит списки и элементы по отдельным путям. Это обзор контракта, не машинная спецификация.

## Пример котировки

```json
{
  "data": {
    "quoteId": "opaque-quote-id",
    "context": {"type": "organization", "id": "opaque-organization-id"},
    "expiresAt": "2026-09-11T12:10:00Z",
    "currency": "RUB",
    "items": [{"sku": "opaque-sku", "quantity": 2, "unitPriceKopecks": 100000, "lineTotalKopecks": 200000}],
    "subtotalKopecks": 200000,
    "discountKopecks": 0,
    "deliveryKopecks": 15000,
    "totalKopecks": 215000,
    "taxes": [],
    "allowedPaymentMethods": ["invoice"],
    "requiredLegalDocuments": [{"id": "terms-b2b", "version": "server-version"}]
  },
  "meta": {"requestId": "opaque-request-id"}
}
```

Пример синтетический; `taxes` в реальном ответе обязателен по налоговому режиму/составу операции. Пустой массив здесь не означает освобождение продавца от НДС. Налоговые значения клиент не придумывает.

## Проверки API до подключения приложения

Нельзя прочитать/изменить чужие адреса, корзины, счета, возвраты и заказы подменой ID или ИНН. После отзыва членства доступ прекращается немедленно. Два одинаковых создания заказа и два одинаковых webhook дают один результат. Изменение цены/остатка до подтверждения вызывает новую котировку с явным подтверждением покупателя. Сбой PSP не превращается в «Оплачено». Логи без телефонов, адресов, реквизитов и токенов. Отдельно проверить 1С обмен и сценарии конкурирующих резервов сайта и приложения.
