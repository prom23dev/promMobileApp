# Референсы нативных приложений для «Промышленника»

Дата проверки: **11 сентября 2026 года**. Исследованы официальные страницы приложений и их галереи iPhone в App Store; дополнительно — Android-галерея ВсеИнструменты.ру в Google Play. Галереи просмотрены визуально через браузер. **Сами приложения на устройствах не устанавливались и не запускались.** Мобильные сайты не использовались как доказательство устройства нативного интерфейса. Промо-рамки и рекламные надписи вокруг телефонов отделены от показанного внутри UI.

## Решения для «Промышленника»

Это проектные выводы, а не утверждение, что все четыре конкурента реализуют каждый пункт одинаково.

| Сценарий | Что переносим в проект |
|---|---|
| Главная | Компактная шапка: город получения, текущий покупатель, поиск. Категории и реальные товары на первом экране. Один полезный промоблок. Нижняя навигация с подписями и счётчиком корзины. |
| Поиск | Поиск по названию, бренду, артикулу; понятная очистка запроса; сохранение запроса при возврате из товара. Быстрое добавление результата в корзину. Камера — только после появления реального сканирования, без декоративной неработающей иконки. |
| Каталог | Две колонки карточек с настоящим фото, ценой, наименованием и действием покупки. Фильтры по техническим параметрам категории, наличию и цене; видимое число применённых фильтров. Сравнение для сложного оборудования. |
| Карточка | Крупное фото, артикул и характеристики; наличие и срок получения рядом с ценой. Закреплённое действие покупки и количество. Документы, расходники, аналоги, отзывы — отдельными понятными разделами, когда имеются реальные данные. |
| Корзина | Количество, удаление, итог и действие оформления доступны без лишних переходов. Показывать склад/срок, выбранного покупателя, адрес, способ оплаты. Конкретная компоновка — собственное решение: полная корзина конкурентов не наблюдалась в изученных галереях. |
| Юрлица | Сохраняемый контекст «Для себя / Для бизнеса» доступен сверху. В бизнес-контексте — выбранная организация, её корзина и заказы, счета, документы, менеджер. Проверка полномочий пользователя выполняется сервером. Смена контекста не переносит молча товары и заказы между покупателями. |
| Визуальный стиль | Светлая нейтральная основа, реальные фотографии инструмента, компактные округлые карточки, читаемая цена, один собственный фирменный акцент. Современность создают ясная иерархия, быстрые действия и качественные товарные данные. Логотипы, палитры и рекламные материалы конкурентов в приложение не копируются. |

## Ограничения доказательств и последующая проверка

- Скриншоты магазинов — выбранные разработчиком примеры. Они не подтверждают все переходы, ошибки, доступность функций каждому аккаунту или идентичность интерфейса iOS и Android.
- Промо-галереи не позволяют измерить время запуска, скорость поиска, плавность прокрутки, расход памяти, работу без сети и удобство ввода. Сравнение скорости с WB/Ozon/Маркетом пока не выполнено.
- B2B-история ВсеИнструменты подтверждена официальными примечаниями к релизам, но сценарии входа, организации, счета и ЭДО лично не пройдены.
- Следующий этап проверки нативной сборки «Промышленника»: реальные iPhone и Android, поиск → фильтр → карточка → корзина → заказ отдельно для двух типов покупателей; возврат назад без потери состояния; крупный текст, VoiceOver/TalkBack; медленная сеть и повторное открытие приложения. Замеры холодного/повторного запуска, p95 API и пропущенных кадров должны быть записаны вместе с моделью устройства, сетью и размером каталога.
