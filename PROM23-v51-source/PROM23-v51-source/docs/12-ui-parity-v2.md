## Надёжность тестового оформления

- Расчёт сбрасывается при изменении контекста, корзины, города или способа получения/адреса; опоздавший ответ старого расчёта не применяется.
- Время расчёта проверяется перед оформлением и сервером. Повтор создания после потери ответа использует тот же `Idempotency-Key`, связанный с ID расчёта; новый ключ не генерируется.
- После успешного создания неудача обновления корзины не превращается в сообщение о неудаче заказа: открывается уже сохранённый заказ.
- Повтор отмены после потерянного ответа перечитывает заказ при `ORDER_ALREADY_CANCELLED`.
- После потерянного ответа удаления тестовой сессии повторный `401` трактуется как уже недействительная сессия; ключ очищается и создаётся новая пустая сессия. Данные действующего сайта не затрагиваются.
- Загрузка данных отменяется при смене экрана/контекста; кнопки операций блокируются на время запросов. Это локальная проверка кода, не доказательство работы на реальном iPhone/Android.

Проверено: `npm run typecheck` — успешно после добавления экранов/маршрутов. Итоговый UI и ограничения приёма необходимо перепроверить после общей сборки, так как соседние файлы разрабатываются параллельно.

## Каталог и корзины

CatalogScreen, ProductScreen, ProductCard, CartScreen и CompareScreen соответствуют C01–C04, C06–C07, C09–C10 матрицы сайта. Функции новых магазинов не добавлены. Свойства фильтров ограничены фактическими полями разделов тестового сайта; производитель не выводится из названия. «Только различия» найдено в frontend/h/comparison.php:80. Служебные SEO/index/PROP-поля скрываются только при отображении, снимок JSON сохранён.

Текущий стенд содержит выборку 25 товаров, а не полный каталог. Выбор города есть, но региональные цены/остатки и реальная доставка не подключены; это не полная реализация C05/C13. Живые варианты товаров, купоны, лист ожидания, калькулятор комплектов, заявки аренды/лизинга/покупки в один клик и остальные сценарии матрицы остаются в объёме переноса сайта и ещё не реализованы целиком.

Перенос бизнес-логики из ВсеИнструменты/Ozon/WB/Яндекс Маркета не выполняется: их нативные галереи использованы только для выбора расположения поиска, категорий, переключателя покупателя и карточек.
