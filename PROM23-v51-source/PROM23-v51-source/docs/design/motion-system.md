# Motion system

Existing Reveal and reduced-motion support are reused. Durations are tokenized: press120ms, state220ms, entry300ms. Animate opacity/transform for purposeful state transitions: selected manufacturing scene, buyer-benefit content, business need option, company FAQ/history and cart feedback.

No autoplay video, forced scroll, exit blocker, continuous decorative loop or modal triggered merely by time. Product/call/contact routes remain direct. `prefers-reduced-motion` and native accessibility preference disable optional transitions; layout/content stays available. Sheet close/back is explicit. Initial home uses a virtualized section feed and bounded product shelves.

Advanced experimental motion and AI personalization remain deferred until P0 source/backend integration is verified. This is deliberate adherence to MASTER4 priority, not an unimplemented animation promise.
