## Контроль потоков

До активации провайдера в D-05…D-17 указать его юридическое лицо, роль (обработчик по поручению/самостоятельный оператор), страны и адреса баз/субобработчиков, цель/основание передачи, договор, срок, механизм удаления, источник сведений и владельца проверки. Подключение российского бренда или российского IP не доказывает российское хранение всех логов/резервных копий.

Источник требований локализации: [23-ФЗ, официальная публикация](https://publication.pravo.gov.ru/document/0001202502280034). Карта должна охватывать прямые SDK-запросы, crash-репорты и CDN — данные не обязаны проходить через backend, чтобы возникла обработка. Правовые основания и сроки вынесены в [processing-register](processing-register.md).

Сохранённый ID сессии, история покупок и IP могут позволять выделить человека. Не объявлять эти данные обезличенными без проверки невозможности обратной связи. Необязательный сбор выключен до выбора; essential-покупка/обращение не зависят от analytics. [Apple: определение collected/linked data](https://developer.apple.com/app-store/app-privacy-details/).

Приёмка карты: релизная сборка на чистом устройстве → сетевые следы guest/login/checkout/permissions deny+allow → сравнение с реестром SDK → проверка удаления/отзыва на staging. Сырые следы с токенами/ПД хранить в закрытом артефактном хранилище, в отчёт только очищенную матрицу endpoint/тип/цель/страна и хеш доказательства.

После перезагрузки показывается восстановление через повторный ввод. Сейчас файл или список не отправляются в Bitrix/CRM/analytics.
