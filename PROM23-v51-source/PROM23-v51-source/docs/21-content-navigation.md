# Полезные разделы сайта и нативный блог

Обновлено 11.09.2026. Источник функций и материалов — [сайт владельца](https://prom.myfast.space/) и переданный site-source. UI использует будущее имя prom23.ru; фактические sourceUrl сохранены без выдуманных ссылок. Существующие файлы навигации и siteContent.ts в этой работе не менялись.

## Реализация блога

- BlogScreen.tsx и app/blog/index.tsx: список, поиск по заголовку/описанию, три реальные рубрики. Вход /blog; рубрика может задаваться ?kind=articles, projects или video.
- ArticleScreen.tsx и app/blog/[id].tsx: нативные заголовки, полный основной текст, списки, таблицы с горизонтальной прокруткой, содержание с переходом, обложка, автор/даты источника, системное «Поделиться». WebView отсутствует. Ссылки каталога ведут к существующему товару/разделу приложения; другие допустимые источники открываются только по нажатию.
- blogContent.ts: 28 исходных записей и 709 текстовых блоков. В списках рубрик и ссылках всех 28 детальных страниц дополнительных публикаций не найдено. Sitemap содержит вход /blog/, но не перечисляет сами статьи — это не использовалось как доказательство их отсутствия.
- 20 собственных обложек, 16 393 719 байт, в assets/blog. [Происхождение и SHA-256](../mobile/assets/blog/provenance.md). Полные галереи/встроенные иллюстрации не скачаны; оригинал доступен из каждой публикации.

## Информационные страницы для «Ещё»

Новый mobile/src/content/sitePages.ts экспортирует sitePages: Record<string, SitePage>, getSitePage(slug), sitePagesCheckedAt. SitePage содержит slug, title, sourceUrl (string либо null), sections [{id,title?,paragraphs:string[],bullets?:string[]}], links? [{label,url}], sourceReviewRequired?:string[], dataContract? {resource,fields,sourcePath?,status:"requires-source"}.

forms? содержит sourcePath, наблюдаемые HTML fields и requiresIntegration:true. Это инвентаризация публичной формы, а не каноническая серверная схема валидации: повторяемые checkbox, правила обязательности и согласия определяются обработчиками. Канонические формы реализуются отдельно в siteForms. Сам модуль ничего не отправляет.

Сопоставление подтверждено с владельцем siteForms: suppliers-form-action.php → supplier; partners-form-action.php → partner (alias franchise). Эти значения также записаны в forms[].formId, чтобы общий экран не терял CTA.

Уже существующие страницы сохраняются отдельно: /information/delivery ← /delivery/, /information/payment ← checkout-код и /payment/, /information/business ← /business/, /information/production ← /vendor/, /information/contacts ← /contacts/. Общий экран «Ещё» должен открыть их вместе с новым блогом/проектами и registry. Кабинет, избранное, сравнение, корзина, уведомления и формы не заменяются внешними переходами.

«Скачать каталог»: кнопка local/templates/main/footer.php:116 использует CATALOG_URL из конфигурации. Действительный файловый URL пока не установлен. Нужен content.catalogDownload {url,filename,mimeType,size,updatedAt}; произвольный PDF не подставляется. Поставщик, партнёр, экскурсия, бизнес-консультация и запрос документа остаются отдельными обязательными действиями с собственными обработчиками.

## Проверка и границы

- Только HTTPS GET, максимум два одновременно. Формы, аккаунты, заказы, CRM и рассылки не затрагивались; исходный PHP не исполнялся.
- HTML преобразован в типизированные текстовые блоки. Исключены script/style/debug, формы как обычный текст, дубли мобильной/настольной разметки, каталожные счётчики, шаблонные отзывы и несоответствующие FAQ-ответы. Полезные блоки каруселей и история сохранены текстом.
- Выполнена отдельная редактура about/brands/suppliers/franchise/awards для мобильного чтения: навигационные CTA вынесены в действительные links/forms; годы истории соединены со своими событиями, повторная лента годов удалена; устаревшее «16 лет» не показывается как текущий факт. Повторённый текст о сертификатах под разными преимуществами убран. Условия поставщика/франшизы представлены списками; проекты открываются через полный нативный блог, без повторного списка в описании франшизы. Юридические тексты не переписывались.
- Проверены уникальность 28 IDs/URL, полнота доступных списков и ссылок, наличие 20 image require, отсутствие script/debug/session-значений в контенте. Внешние переходы ограничены HTTPS и доменами собственного сайта/Rutube/YouTube.
- Повторный общий TypeScript-запуск после появления siteForms завершился успешно (exit 0). Дополнительно проверены 28 публикаций, 20 файлов изображений, 17 страниц, очищенные CTA/годы и привязки supplier/partner. Экспорт и визуальный проход выполняет основной агент после объединения. Установка, системное Share и внешний плеер на телефоне ещё не проверены.
- Это версионированное содержимое, а не настроенная синхронизация Bitrix. Контракт публикаций для подключения: id, kind, title, excerpt, publishedAt?, modifiedAt?, author?, readTime?, blocks, links, images, sourceUrl. Серверная пагинация/обновление должны сохранять текущее чтение и пустые состояния.

Исходники: site-source/blog/index.php (IBLOCK/URL templates), local/templates/main/components/bitrix/news/blog/{news,projects,video,detail,result_modifier}.php, list templates, about/brands/franchise/suppliers/delivery/index.php. Заголовки/даты получены из опубликованного HTML/JSON-LD. Юридические тексты не редактировались ради нового бренда и не объявлены прошедшими правовую проверку.
