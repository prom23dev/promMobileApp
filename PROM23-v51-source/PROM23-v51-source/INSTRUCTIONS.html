Промышленник — исходники версии 51 для iOS и Android

Срез приложения соответствует опубликованной версии v0.10-20260918-51 от 18 сентября 2026 года.

Проверить интерфейс: http://159.253.19.172:18087/pages/about?v=51

Это общий редактируемый проект React Native / Expo с проектами для Xcode и Android Studio, сервером и материалами. Подписанных установочных IPA, APK и AAB в комплекте нет. Нативные проекты заново сгенерированы из текущего app.json; это не результат компиляции на устройствах.

Что внутри

• mobile/app/ — маршруты и страницы приложения.

• mobile/src/ — экраны, компоненты, тексты, состояние, запросы к API.

• mobile/src/content/ — тексты компании, филиалы, награды и другие разделы.

• mobile/src/ui/theme.ts — основные стили; остальные UI-компоненты — рядом.

• mobile/assets/, mobile/public/ — фото, иконки, логотипы, шрифты, документы.

• mobile/ios/ — свежий проект Xcode Promyshlennik.xcodeproj, Swift, plist, Podfile.

• mobile/android/ — свежий проект Android Studio, Kotlin, Gradle, manifest и ресурсы.

• mobile/app.json, package.json, package-lock.json, eas.json — конфигурация и зафиксированные зависимости.

• mobile/dist/ — экспорт текущей версии для web, iOS и Android. Файлы .hbc — JavaScript-байткод Hermes, а не установочные приложения.

• server/, preview/ — сервер Node.js и локальный просмотр.

• server/location/data/gar.sqlite — публичный справочник населённых пунктов; это не база клиентов/заказов.

• data/ — снимок каталога и публичного контента.

• integrations/ — исходники подготовленных адаптеров Bitrix и инструкции подключения.

• scripts/, mobile/tests/, server/test/ — утилиты и проверки.

• docs/ — техническая документация и история решений. Старые отчёты описывают свои версии; актуальный статус указан здесь и в docs/ux51/REPORT.md.

• SOURCE_MANIFEST.json — список файлов и SHA256 для проверки целостности.

Включены все отслеживаемые исходники текущего приложения, его ресурсы и справочник GAR. Не включены устанавливаемые зависимости node_modules/Pods, кэши, Git-история, предыдущие релизные архивы, старые папки скриншотов docs/parity/evidence и docs/testing/evidence, серверные сессии и ключи владельца. Исходный архив старого сайта Bitrix отдельно не дублируется: он не является кодом этого приложения. Шаблонный android/app/debug.keystore создан Expo для локальной отладки; он не является ключом издателя.

Быстрый локальный просмотр

Понадобится Node.js 24 (в проекте указан 24.19.0) и npm. В корне распакованного проекта:

npm --prefix mobile ci
npm --prefix mobile run typecheck
npm --prefix mobile test
npm --prefix server test
node preview/index.mjs

Откройте http://127.0.0.1:8087. В архиве уже есть mobile/dist/, поэтому первый просмотр не требует пересборки. После изменения исходников:

npm --prefix mobile run export
node preview/index.mjs

Для web-разработки с горячим обновлением можно использовать npm --prefix mobile run web, настроив доступ к API. Основной проверенный просмотр — сервер preview/index.mjs, который отдаёт web и API на одном адресе.

API на iPhone и Android

Для физического устройства нужен доступный ему сервер с HTTPS. Текущий HTTP-адрес по IP используется для браузерного просмотра. Перед нативной сборкой задайте адрес своего BFF в mobile/.env.local:

EXPO_PUBLIC_LOCAL_API_URL=https://YOUR-API-HOST/api
EXPO_PUBLIC_APP_API_URL=https://YOUR-API-HOST/api

Замените YOUR-API-HOST на реально настроенный адрес. Это URL сервера, не секретный ключ. Не помещайте пароли в EXPO_PUBLIC-переменные. Они попадают в приложение. Адрес 127.0.0.1 на физическом телефоне указывает на сам телефон.

Apple / iOS

Нужны macOS, полный Xcode для Expo SDK 57 (по документации — 26.4+), CocoaPods, iOS Simulator или устройство. После установки зависимостей и настройки API:

cd mobile
npx expo run:ios

Команда устанавливает необходимые нативные зависимости и запускает сборку. Для работы в Xcode после установки Pods откройте ios/Promyshlennik.xcworkspace. Исходный .xcodeproj и Podfile входят в архив; workspace с зависимостями создаётся при установке Pods.

Перед выпуском настройте Apple Developer Team, подпись и окончательный bundleIdentifier. Сейчас используется тестовый ru.prom23.preview, версия приложения в app.json — 0.9.0. Номер web-релиза 51 не является номером версии App Store. IPA и загрузка в App Store в этом комплекте не выполнялись.

Google / Android

Нужны Android Studio, JDK и Android SDK, совместимые с включённым Gradle-проектом. Параметры SDK определяются проектом Expo 57. После настройки API:

cd mobile
npx expo run:android

Для редактирования откройте папку mobile/android в Android Studio. Для выпуска настройте окончательный package ID, versionCode и собственный upload key, затем соберите подписанный Android App Bundle. Текущий ID — ru.prom23.preview. Шаблонная debug-подпись не подходит для публикации.

Что править и как сохранять изменения

Основной код общий для обеих платформ: mobile/app, mobile/src, mobile/assets и mobile/app.json. Изменения в этих файлах попадут в обе сборки. iOS/Android-папки созданы командой:

npx expo prebuild --no-install --platform all

После изменений конфигурации/плагинов их можно пересоздать через prebuild. --clean удаляет существующие нативные папки: предварительно сохраните ручные изменения. Постоянные нативные настройки лучше закреплять в app.json/config plugins. EAS по умолчанию использует gitignore и может заново создать игнорируемые native-папки; перед передачей ручных нативных изменений настройте их включение.

Часть исторических QA-скриптов содержит пути прежнего рабочего компьютера. Для нового окружения адаптируйте их пути; они не нужны для запуска приложения.

Текущее состояние интеграций и публикации

По поручению владельца подключение Битрикс пропущено. Каталог работает со снимком данных; реальные авторизация, заказы, оплата, документы и другие внешние операции требуют подключения и проверки адаптеров из integrations/. Успех таких операций не имитируется. Настройка APNs/FCM и испытания нативных сборок на устройствах также ещё не выполнены.

eas.json содержит профиль внутренней preview-сборки. Производственный релизный профиль не настроен; check:release и EAS gate сохраняют прежнее ограничение. Старый текст gate — ориентир на оставшиеся интеграционные работы, актуальные утверждённые тексты документов уже находятся в исходниках. Завершение этих работ и подпись нужны до публикации в магазинах.

В этом комплекте проверены: совпадение кода приложения с версией 51, создание свежих iOS/Android-проектов, TypeScript, 190 серверных тестов и целостность архива. Один тест диагностики Bitrix переведён на синтетический локальный пример, чтобы проверки запускались без отдельного архива старого сайта; код приложения и сервера не изменён. В версии 51 ранее прошли web/iOS/Android export, 9 API-тестов и 27 локальных + 27 публичных UI-проверок. На компьютере передачи нет полного Xcode и Java Runtime, поэтому компиляция IPA/APK/AAB не заявляется.
